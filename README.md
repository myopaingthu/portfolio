# Myo Paing Thu — Portfolio

An editorial portfolio for Myo Paing Thu, built to make the work, systems, and thinking behind each project feel as intentional as the finished product.

## Live site

Live URL: https://myopaingthu.vercel.app/

## Built with

- Next.js and React
- TypeScript
- Tailwind CSS
- GSAP and Lenis for motion and smooth scrolling
- Three.js for the ambient particle field

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

Useful commands:

```bash
npm run lint
npm run build
npm run start
```
